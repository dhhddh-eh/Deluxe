# LazyMedia Deluxe

Демо-приложение каталога фильмов на Flutter.

## Что внутри
- Список легальных public domain / Creative Commons фильмов.
- Демо-Pro: поиск и избранное.
- Сохранение Pro-флага и избранного через SharedPreferences.
- Открытие легального источника фильма во внешнем браузере.
